## 4. Yêu cầu chức năng

### 4.1 `experiments/run_exp.sh`
Cách gọi: `bash experiments/run_exp.sh <SCRIPT> <NONCE> <TAG> [PY]`. `PY` mặc định là `python`.
1. Thiếu `SCRIPT`, `NONCE` hoặc `TAG` → in lỗi ra stderr, thoát với mã ≠ 0, **không** tạo log.
2. Tạo `logs/` nếu chưa có. Chạy `PYTHONUTF8=1 PYTHONIOENCODING=utf-8 "$PY" -u "$SCRIPT" --nonce "$NONCE" 2>&1 | tee "logs/$TAG.log"`.
3. Mã thoát phải là mã của **python**, lấy từ `${PIPESTATUS[0]}`, không phải của `tee`. Ghi thêm dòng cuối `[EXIT] code=<mã>`.
4. Ghi `logs/$TAG.numbered.txt` với từng dòng dạng `printf '%4d| %s'`, giống `run_exp.ps1:42`.
5. In `[HASH] <sha256 của logs/$TAG.log>`.
6. Thoát với đúng mã của python.
7. Log và file numbered phải là **UTF-8 không BOM, xuống dòng LF**.

### 4.2 `notebooks/kaggle_runner.ipynb`
Tối đa 6 code cell; mỗi cell ≤ 15 dòng; **không import `src`, không chứa logic thí nghiệm**.
1. **Tham số:** `REPO_URL` (mặc định `https://github.com/Dung34/vector-kv-cache.git`), `COMMIT`, `SCRIPT`, `NONCE`, `TAG`, `TRANSFORMERS_VERSION` (mặc định `5.20.1`, trùng với local). Cell này `assert` các điều sau:
   - `COMMIT` là SHA đủ 40 ký tự hex;
   - `NONCE` không rỗng;
   - `TAG` chỉ gồm `[A-Za-z0-9_.-]`.
2. **Ghim code:** clone repo, `git checkout $COMMIT`, rồi `assert git rev-parse HEAD == COMMIT`. In `git status --porcelain`.
3. **Môi trường:** `pip install -q transformers==$TRANSFORMERS_VERSION accelerate`, sau đó in `nvidia-smi`. Có GPU hay không thì cell vẫn chạy, chỉ in ra kết quả.
4. **Chạy:** `bash experiments/run_exp.sh "$SCRIPT" "$NONCE" "$TAG" python`. Nếu mã thoát ≠ 0, cell báo lỗi rõ ràng, không được nuốt lỗi.
5. **Đóng gói:**
   - Dùng `zipfile` của Python (không dùng `zip`) để nén `logs/` và `results/` (nếu có) thành `evidence_<TAG>.zip`, đặt ở `/kaggle/working/` nếu thư mục đó tồn tại, nếu không thì ở thư mục hiện tại.
   - Kèm `MANIFEST.txt` liệt kê từng file với sha256 và số byte, cùng `COMMIT` và `NONCE`.
   - In sha256 của file zip.

## 5. Các bước
1. Viết hai file test **trước**. Chạy khi chưa có runner/notebook, lưu log FAIL.
   → `.venv_v5/Scripts/python.exe -m pytest tests/test_run_exp_sh.py tests/test_kaggle_runner_notebook.py -q 2>&1 | tee logs/phase5_2_test_fail.log`
2. Viết `run_exp.sh`, `.gitattributes` và notebook để test PASS.
   → cùng lệnh, `tee logs/phase5_2_test_pass.log`
3. **Đột biến:** trong `run_exp.sh`, thay `${PIPESTATUS[0]}` bằng `$?`. Lúc đó mã thoát là của `tee`, luôn bằng 0. Test mã thoát phải FAIL → `logs/phase5_2_test_mutation.log`. Sau đó hoàn tác.
4. Chạy demo **bằng chính `run_exp.sh`** trên máy local (Git Bash). Lệnh ở mục 7.
5. Chạy toàn bộ suite → `.venv_v5/Scripts/python.exe -m pytest tests/ -q 2>&1 | tee logs/phase5_2_full_pytest.log`

**Lưu ý:** dùng `tee` của bash cho mọi log ở brief này, không dùng `Tee-Object`, để mọi log của 5.2 là UTF-8.

## 7. Lệnh chạy demo (Git Bash, local)
```bash
bash experiments/run_exp.sh experiments/phase5_header_demo.py <NONCE> phase5_2_runner_demo .venv_v5/Scripts/python.exe
file logs/phase5_2_runner_demo.log
```
Người dùng cung cấp `<NONCE>`. **Không tự đặt.** Yêu cầu:
- dòng 1 của log là `[HEADER] nonce=<NONCE> …`;
- dòng cuối là `[EXIT] code=0`;
- `file` báo `UTF-8` hoặc `ASCII text`, **không** báo `UTF-16`.

Brief này **không** chạy trên Kaggle. Lần chạy GPU đầu tiên là task 5.3, cần commit đã được push lên GitHub.
